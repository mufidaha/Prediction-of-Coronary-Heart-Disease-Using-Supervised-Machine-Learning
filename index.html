How I built it

Python (pandas, scikit-learn, XGBoost). Checked the data for missing values (none), encoded family history as 0/1, split 70/30 (random_state=7), trained decision tree, SVM, random forest, logistic regression, k-nearest neighbors and XGBoost, then compared accuracy, AUC, precision and recall. My original class notebook chose the random forest on accuracy (69.8%); re-running with AUC and recall shows logistic regression ranks patients slightly better and that SVM's accuracy is misleading. This is a teaching dataset, not a clinical tool.

Data source

South African Heart Disease data (Rousseauw et al., 1983), as distributed with The Elements of Statistical Learning. 462 male patients, 9 risk factors. Re-run November 2026.
